# 金融研究仪表盘 — 转录库交互原型 v1.0

## 功能树总览

```
转录库
├── 📊 总览
│   ├── 统计卡片（4个）
│   ├── 分类分布
│   └── UP主活跃度
├── 👤 UP主管理
│   ├── UP主列表（卡片）
│   ├── [添加UP主] 弹框 ⬅️ NEW
│   ├── [编辑UP主] 弹框 ⬅️ NEW
│   ├── [删除确认] 弹框 ⬅️ NEW
│   └── UP主详情展开
│       └── [新建采集任务] 弹框 ⬅️ NEW
├── 📋 浏览
│   ├── 筛选工具栏
│   ├── 视频列表
│   ├── 视频展开预览
│   └── [视频详情] 侧边面板
│       ├── 基本信息
│       ├── 全文浏览
│       ├── 因子标注
│       └── [引用] 复制
└── 🔑 因子
    ├── 因子分类卡片（4类）
    ├── 因子关键词列表
    ├── [添加关键词] 弹框 ⬅️ NEW
    ├── [编辑关键词] 弹框 ⬅️ NEW
    └── 因子搜索
```

## 6. 交互流程总结

### 6.1 添加UP主 → 创建任务 完整流程

```
用户点击 [+ 添加UP主]
    │
    ▼
弹出 [添加UP主] 弹框
    │
    ├─ 输入UID → 点击 [自动填充] → 抓取B站信息
    │
    ▼
确认添加 → 调用 createUp() → Toast "✅ 添加成功"
    │
    ▼
UP主列表刷新，显示新UP主卡片
    │
    ├─ 点击 [新建任务]
    │
    ▼
弹出 [新建采集任务] 弹框
    │
    ▼
配置范围/频率/转录方式 → [创建任务]
    │
    ▼
调用 writer.js 创建任务 → 可选创建 Calendar 定时日程
    │
    ▼
Toast "✅ 任务已创建" → 任务进度条出现在UP主卡片中
```

### 6.2 视频浏览 → 因子标注 完整流程

```
浏览Tab → 筛选视频 → 点击视频展开
    │
    ├─ 点击 [查看详情→] → 侧边面板滑入
    │
    ▼
查看全文（按需加载）
    │
    ├─ 发现因子标注缺失 → 点击 [+ 添加因子标注]
    │
    ▼
弹出 [添加因子] 小弹框
    │
    ▼
选择类型 + 输入关键词 → 保存
    │
    ▼
因子标注更新，factor_keywords.json 写入
```
